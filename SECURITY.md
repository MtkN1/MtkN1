# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in any of my projects, please report it responsibly.

### How to Report

Please report security vulnerabilities by:
- Opening a security advisory on the specific repository
- Contacting me directly via [X/Twitter](https://x.com/MtkN1XBt)

### What to Include

When reporting a vulnerability, please include:
- Description of the vulnerability
- Steps to reproduce the issue
- Potential impact
- Suggested fix (if available)

### Response Time

I will try to respond to security reports within 48-72 hours and will work to address valid issues as quickly as possible.

Thank you for helping to keep my projects secure!
